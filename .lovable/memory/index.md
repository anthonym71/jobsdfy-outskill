# Project Memory

## Core
JobsDFY (jobsdfy.com) - job seeker app. Space Grotesk headings, DM Sans body. Primary deep navy #1B2A4A. Verdict: green GO, amber REVIEW, red STOP.
Lovable Cloud enabled. Auth via Supabase. All colors via HSL design tokens.
Protective-first UX: dealbreakers before fit score, fit before quick apply. Nothing auto-sends.
No LinkedIn credential automation — security/ToS risk. Chrome extension + smart paste instead.
Mascot: "Joby" — navy superhero character. Used for branding, Voice AI persona, in-app references.
